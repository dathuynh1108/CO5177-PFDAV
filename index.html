01 About the course

Course information

The project applies Python and data analysis libraries to three classification tasks. Notebooks contain the analysis; separate PDF reports describe the methods and findings.

Tabular uses UCI Adult. Text uses the VietnamNet corpus collected by Huỳnh Thành Đạt. Image reuses the CIFAR-100 experiments from CO5085 A1.

03 Method

Experimental procedure

Each study records its source data, split and model settings. The notebooks link the measured artifacts to the analysis and provide commands for rerunning the experiments.

Step 01

Explore

Record the source, inspect missing values and duplicates, and plot class distributions.

Step 02

Prepare

Fix the split before model fitting. Learn preprocessing statistics from training data.

Step 03

Model

Fit baselines and alternatives; choose model settings using validation results.

Step 04

Explain

Report held-out metrics, confusion patterns, computational costs and limitations.
