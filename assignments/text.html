Planned workflow

  1. Explore the corpus. Inspect sample texts, document lengths, label distributions and duplicates.
  2. Prepare the text. Define a language-appropriate cleaning and tokenization pipeline while preserving useful information.
  3. Represent and model. Start with a reproducible baseline, such as TF-IDF features and a Scikit-learn classifier when the task is classification.
  4. Evaluate and interpret. Compare models on the same split, examine confusion patterns and inspect representative errors.
Possible extensionCompare TF-IDF with embeddings, or analyze class-discriminative words and n-grams. Include numerical comparisons and examples that explain model errors.
