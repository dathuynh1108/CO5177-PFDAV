Project overview

Investigate a real-world tabular dataset using exploratory data analysis, preprocessing and machine learning. The final problem statement and target variable will be defined with the selected dataset.

  • Numerical columns suitable for scaling.

Planned workflow

  1. Understand the dataset. Document its source, column definitions, distributions and missingness.
  2. Prepare the data. Address missing values and outliers; encode categorical features and scale numerical features as appropriate.
  3. Build a baseline. Define train, validation and test splits. Fit preprocessing on training data only.
  4. Compare and explain. Evaluate models consistently, inspect errors and link conclusions to measured results.
Possible extensionCompare a baseline with an imbalance-aware or outlier-aware approach. Include a figure with a clear question, quantitative comparison and evidence-backed conclusion.
