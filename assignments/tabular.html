Study overview

The task predicts whether annual income exceeds $50,000 in this historical Census dataset. The study examines missing values, mixed feature types and class imbalance, then compares majority, logistic and histogram gradient boosting classifiers.

Dataset

UCI Adult · 48,842 source rows · 14 features

48,780 records remain after removing conflicting labels and repeated feature rows. A new stratified 70/15/15 split is used; this is not the original official test split.

Source: course assignment brief v4.0, section 4.2. These are minimum requirements, not completed dataset statistics.

Method

  1. Data quality. Ten records in feature-identical groups with opposing labels are removed, followed by 52 repeated rows. Missing values occur in workclass, occupation and native country.
  2. Preprocessing. Imputation, scaling and categorical encoders fit training data only. Unseen categories are handled explicitly.
  3. Model selection. Logistic C is selected by validation macro-F1. Gradient boosting uses a fixed configuration; test predictions are made after all choices finish.
  4. Evaluation. Accuracy, macro-F1, class-specific precision/recall and confusion are computed on 7,317 held-out records.

Held-out results

One fixed stratified split. Classifier settings are selected using validation macro-F1.
ModelAccuracyMacro-F1
Majority baseline76.06%0.4320
Logistic regression85.24%0.7815
Balanced logistic regression81.43%0.7769
Histogram gradient boosting87.48%0.8185

Histogram gradient boosting reaches 87.48% test accuracy and 0.8185 macro-F1. Balanced logistic regression increases recall for the minority class at the cost of lower precision. These measurements use one split and model seed.

Full settings, data checks and limitations are documented in the report and experiment protocol.
